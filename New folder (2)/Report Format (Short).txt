Report Format (Short) — รูปแบบรายงานย่อรายวัน
(คู่กับ Report Format.txt เต็มรูปแบบ — ใช้ไฟล์นี้เวลาผู้เล่นแค่อยากดูผลลัพธ์
 เฉยๆ ไม่ต้องตรวจสอบที่มาการคำนวณ ประหยัด token กว่ามาก ไม่มี raw data
 ของ customer rolls/ratio ให้ตรวจย้อนหลัง — ถ้าต้องการตรวจสอบละเอียดให้ใช้
 Report Format.txt แบบเต็มแทน หรือดูข้อมูลดิบที่ sim_daily_log.json)
═══════════════════════════════════════

📌 ใช้เมื่อผู้เล่นขอรายงานแบบสั้น/แบบย่อ/"ดูผลลัพธ์เฉยๆ" หรือระบุชื่อไฟล์นี้ตรงๆ
   ถ้าไม่ระบุอะไรเลย ให้ถามหรือใช้ Report Format.txt (เต็ม) เป็นค่าเริ่มต้น

📌 โครงสร้าง: หัวเรื่อง + ตารางสรุปเดียว + ปุ่มกดท้ายรายงาน (เหมือนแบบเต็ม)
   ไม่มี Active Scope Confirmation และไม่มีหัวข้อ [1]-[7] แยก

📌 ห้ามใช้คำว่า "คอขวด" เหมือนกฎในแบบเต็ม — ใช้ "ตัวที่ขาด" แทนเสมอ

📌 ตารางเป็น markdown table จริง (ต่างจากแบบเต็มที่ใช้ plain text ใน code
   block) เพราะจุดประสงค์คืออ่านง่าย/สวย ไม่ใช่ตรวจสอบตัวเลขดิบ

─────────────────────────────────────
**สรุปวันที่ {N}**

| รายการ | ผลลัพธ์ |
|---|---|
| ลูกค้า | {customers} คน (แวะ {customers}/{N คนในละแวก}) |
| ผลิต | {เมนู1} {n}, {เมนู2} {n}, {เมนู3} {n} |
| ขายได้ | {เมนู1} {n}, {เมนู2} {n}, {เมนู3} {n} {— ขายหมดทุกเมนู ถ้าของเหลือ=0 ทุกเมนู} |
| เดินหนี | {n} คน {(ในนั้น {walkAwayChanceHits} คนเดินหนีเองทั้งที่ของยังพอ) ถ้า >0} |
| รายรับ | {revenue} บาท |
| ต้นทุนผลิต (รวมของเสียไข่) | {totalCostWithWaste} บาท |
| เติมสต็อก | {วัตถุดิบ} {จำนวน} ({ราคา} บาท), ... → รวม {reorderCost} บาท {หรือ "ไม่มีการเติมสต็อก" ถ้าไม่มี reorder จริง} |
| เงินสด | {cashStart} → **{cashEnd} บาท** |
| หมายเหตุ | {สรุปสั้น: วัตถุดิบไหนใกล้หมด/ต่ำกว่าเกณฑ์ก่อนเติม, ตัวที่ขาดถ้ามี, อะไรน่าสังเกต — ไม่บังคับต้องมีทุกวัน} |
